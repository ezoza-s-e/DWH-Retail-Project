# DWH-Retail-Project
• Designed DWH for a retail network with two data sources (online store and offline ERP/POS), combining them into a single model • Defined grain, dimensions, and facts; built a 3NF layer (Geography - 6 levels, Product — 3 levels) with SCD Type 2 for customer history • Designed a dimensional model (star schema): FCT_SALES + 6 dimension tables
